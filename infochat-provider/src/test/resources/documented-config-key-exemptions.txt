# Documented-config-key exemptions — read by DocumentedConfigKeyParityTest (M1-708).
#
# Format: <pattern> | <reason>
#   `*` matches one or more characters within a single dot segment. An entry
#   must be bounded (>= 2 literal segments); `infochat.*` and friends are
#   rejected by exemptionEntriesCannotBeUnboundedWildcards so a catch-all can
#   never silently disable the gate.
#
# This is a LEDGER, not a suppression list. Every entry states why the key is
# absent from the real key set, and an exemption whose reason has expired must
# come out with the change that expires it — an exemption outliving its gap is
# the failure mode this file is most at risk of. In particular: a doc that
# states a REQUIREMENT the code has not built keeps the requirement and gets an
# exemption citing the gap. Never edit the doc to match the code to green this
# test.
