# scripts/lint-contracts-baseline.txt
#
# Grandfather list for scripts/lint-contracts.py. Each non-comment line is
# a `<path>:<method-name>` entry that suppresses lint findings for that
# specific method on that specific path. The grandfather pattern lets the
# JSpecify parameter-contract rule (CLAUDE.md §"Method parameter
# contracts") roll out incrementally: today's M1-050 retroactive pass
# covers the 4 named boundary classes only; this file stays essentially
# empty until follow-up tickets widen the retroactive pass to *Service
# classes, handler implementations, and infochat-collector boundaries.
#
# Format:
#   <relative-path-from-repo-root>:<method-name>          # optional trailing comment
#
# Example (illustrative — these entries are NOT active in v1):
#   # infochat-provider/.../AddSourceCommandHandler.java:handle
#   # infochat-collector/.../FeedFetcher.java:fetch
#
# Rules:
#   - One entry per line.
#   - `#` starts a comment; the rest of the line is ignored.
#   - Blank lines are skipped.
#   - The match is by literal `path:method` string; substring matches do
#     NOT suppress (use the full method name as it appears in source).
#   - When a future retroactive pass annotates a grandfathered method,
#     the corresponding baseline entry SHOULD be removed in the same
#     commit so the lint regression is mechanically visible.
