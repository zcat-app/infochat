## Findings and UX smells

### F1 — Unicode sanitizer boundary regression — release blocker

The sanitizer strips a dotted internal configuration identifier when it is
immediately preceded by the Unicode letter `é`. This violates the intended
letter/digit boundary contract and is already captured by a failing regression
test. Fix the shared core implementation, then rerun the full sanitizer batch
and the Collector translation-sanitizer coverage.

### F2 — SimpleX attachment remains a file invitation — low-severity UX smell

The raw SimpleX client showed a separate blank attachment item with file status
`rcv_invitation`, followed by the text “Image generated. Prompt used: …”. The
recipient must accept/download the file before it becomes a local image. This
may be normal SimpleX client behavior, but the user experience is not a single
obvious “image received” event and should be checked against the supported
client UX.

### F3 — Missing embedding backend is degraded but not readiness-failing

The Provider started healthy while its configured embedding endpoint pointed at
an absent `ollama` service. Command-intent corpus construction failed at
startup, leaving help intent matching degraded while the service remained
available. The fixed help surface still works, but fuzzy/help suggestions may
not. This is an operational configuration smell in the test deployment and
should either be made an explicit supported degraded mode or fail readiness
with actionable guidance.
