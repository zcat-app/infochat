RED-TEAM VERDICT: CLEAN

This diff is a straightforward, security-neutral refactoring. The SSRF guard
pipeline commitments from the spec (scheme allowlist, DNS resolution + IP
blocklist per hop, redirect cap, timeout caps, body-size cap, body-read
deadline) are all preserved in the surviving `get(URI, Map)` method. The
delegation from `get(URI)` to `get(URI, Map.of())` is functionally identical
to the removed inline implementation.

Key security-relevant observations:

1. **get(URI) to get(URI, Map.of()) delegation preserves the SSRF guard
   pipeline.** The `get(URI, Map)` method has the identical pipeline: scheme
   check, userinfo gate, DNS resolution, IP blocklist, DNS pinning, redirect
   handling, bounded body read. Lock acquisition/release pattern is identical.

2. **Removing compat constructors creates no bypass.** The removed constructors
   all delegated to the full 7-param constructor with default values. Callers
   must now explicitly provide all parameters.

3. **Connect timeout change from 10s to 5s reduces attack surface.** Aligns
   with design spec and shortens the connection-phase attack window.

4. **No new header injection surface.** The `extraHeaders` map in
   `get(URI, Map)` is pre-existing code. This diff only makes `get(URI)`
   delegate with an empty map.
