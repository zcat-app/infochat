RED-TEAM VERDICT: CLEAN

OUT-OF-MODEL:
  - Engagement-metric manipulation of digest ranking: `post.reposts` and
    `post.likes` are feed-publisher-supplied values (untrusted ingest
    content per the threat model's own Collector assumption). A publisher
    who can inflate engagement counts on their own posts wins the
    within-kind social percentiles and steers within-section ordering,
    potentially pushing competing clusters into the per-section "+N more"
    overflow. The threat model commits to ingest sanitization and
    quarantine for *content*, but makes no commitment that ranking/ordering
    is manipulation-resistant, so this is noted for a possible model
    extension rather than counted as a finding.
  - `urgent`-gate gaming: any post whose ingest classification includes
    `urgent` sorts ahead of all higher-scoring clusters in its section
    (ClusterProminence.totalOrder, urgent arm first). If the upstream
    classifier can be swayed by crafted feed content, an attacker buys
    section-head placement. The classification pipeline is upstream of this
    diff and its assigner trust level is not specified in security.md;
    flagged so the user can decide whether classification-integrity belongs
    in the model.
