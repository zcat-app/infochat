OUT-OF-MODEL:
  - Image reference not digest-pinned. prod/scripts/backup.sh:43 sets
    IDENTITY_TAR_IMAGE="pgvector/pgvector:pg16" (a floating tag, not a
    sha256 digest) and runs it as `docker run --rm -u 0:0 ... tar` over
    the identity dirs (line 184). A poisoned registry/tag could execute
    attacker code as root with the identity dirs bind-mounted. This is a
    supply-chain attack on operator infrastructure, which security.md
    §Threat model places explicitly out of scope for v1 ("supply-chain
    attacks on operator infrastructure"). Flagged for the operator's
    awareness only; not a threat-model violation.
  - Backup artifact holds cleartext identity keys. The tgz produced at
    backup.sh:185 contains the SimpleX keypair and signal-cli account
    store in the clear, now readable by the non-root deploy user that
    invokes it. security.md §What's intentionally NOT in v1 assigns
    at-rest protection to the operator ("DB-at-rest encryption —
    operator's responsibility"); the backup.sh header comment already
    states this. The deploy user is a trusted principal, not an
    adversary in the documented model. Not a finding.
