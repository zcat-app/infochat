RED-TEAM VERDICT: CLEAN

The M1-238 diff hardens three points in the Signal adapter's group inbound path and introduces no gap against the documented threat model:

- `SignalMentionParser.botMentioned` (SignalMentionParser.java:57-78) swaps `String.equals` for `MessageDigest.isEqual` over lower-cased UTF-8 bytes. Match semantics are preserved (case-insensitive ACI match, rejects non-matching and null `uuid`), upholding the D10 cryptographic-identity anchor (trust boundary 1, "Display-name-based @mention recognition out of v1"). The equal-length constant-time property satisfies the spec's "leading bytes shared must not leak via timing"; a length-mismatch early return leaks only "wrong length" against a fixed 36-char ACI, not shared-prefix length.

- `SignalGroupHandler.handleReceive` (SignalGroupHandler.java:157-164) routes the group timestamp through the total `usableTimestamp` helper and drops the frame on a missing/null/non-numeric/fractional/out-of-range value instead of throwing NPE/CCE/ArithmeticException out of the handler. This *closes* the adapter-DoS shape the `extractDm` docstring documents (an escaping exception killing the inbound-processing thread → "permanently deaf adapter with no restart trigger"), aligning the group path with the DM path. The guard fires only after the mention gate (line 147), so a non-mentioning sender never reaches the parse — no new amplification.

- `SignalMessageCodec.usableTimestamp` (SignalMessageCodec.java:215) widened from `private` to package-private within the same package; no trust-boundary change. DM and group paths now share one total reference implementation, satisfying the "guarded identically" parity.

No authentication, authorization, ban-handling, audit, or LLM-tool surface is touched (consistent with the sensitive-surface inventory). The attacker-influenced `timestamp` feeds `InboundMessage.receivedAt` / `adapterMessageId`, but the threat model makes no integrity commitment about inbound Signal timestamps (only identity is anchored), and the value is a `Long` so it carries no log/header-injection vector.
