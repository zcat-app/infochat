1. Prior AUDIT-EVASION (medium, rounds 1-2) — VERIFIED CLOSED.
   The collector-side sanitize path in IngestTranslationWorker now emits
   the spec-committed audit rows, and the emission was checked against
   each element of the commitment:
   - Correct aggregation: sanitize() (diff hunk
     IngestTranslationWorker.java, emitAuditRows) aggregates
     result.matches() via the shared
     LlmOutputSanitizerCore.aggregateMatchCounts — the identical
     aggregator the provider bean uses — one row per distinct token per
     sanitize call, details_json.match_count carrying the exact
     occurrence count (counted, never throttled). The WARN stream is
     aggregated from the same match list, so WARN-vs-row stays 1:1.
   - Fail-closed durability: emitAuditRows runs BEFORE the storage
     UPDATE (cleanTitle/cleanBody are evaluated as arguments of
     persistTranslation, so both audit emissions complete before the
     cursor UPDATE executes), writes all rows in a single transaction,
     and throws IllegalStateException on SQLException — processOne
     propagates, onTick logs via SafeLog, the post stays
     translation_done=FALSE and is retried next tick. Nothing is stored
     un-audited. The audit-before-effect ordering matches Invariant 7's
     documented posture (audit row survives a failed side effect).
   - No new surface from the remediation itself: details_json is built
     from an Integer and a closed-list literal through JsonEscaper (no
     injection, no user-authored prose — D37/§Secrets handling
     respected); the collector role's INSERT-only grant on audit_log is
     exactly what the spec assigns it; every storage path that persists
     translator output (TRANSLATED arm) goes through cleanTitle/
     cleanBody, and the en-source / refusal / release arms store only
     NULLs, so no bypass exists. Distinct-token blowup is bounded by
     the 34-entry closed list; same-token blowup is bounded by
     aggregation.
   - IT coverage: IngestTranslationWorkerIT.assertSanitizeAuditRow
     pins the row's existence, surface target_id
     ('ingest-translator-output'), token, and exact count on the
     end-to-end path.

2. Prior INJECTION (low, round 1, renderPrompt substitution order) —
   RE-CONFIRMED CLOSED. renderPrompt substitutes {{id}} and
   {{SOURCE_LANGUAGE}} (both trusted values) before splicing untrusted
   content, and {{body}} before {{title}}, so a title carrying the
   literal "{{body}}" stays literal text; the delimiter id is replaced
   before any untrusted bytes enter the template, so content cannot
   affect the wrapper. The symmetric {{title}}-in-body case only
   duplicates the already-present short title, acknowledged in the
   method javadoc. Unit test
   renderPrompt_titleContainingBodyPlaceholderStaysLiteral pins it.
