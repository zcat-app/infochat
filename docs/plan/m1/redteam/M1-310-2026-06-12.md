fetcher bodies (RSS, Nitter, Odysee, YouTube) are extracted into one shared
`SingleGetFetch.fetchAndParse` helper. No threat-model commitment is undelivered.

  inside `SsrfGuardedHttpClient.get(URI)` (infochat-ssrf .../SsrfGuardedHttpClient.java:325).

  SingleGetFetch.java:187), so scheme allowlist, IP blocklist, DNS pinning,
