RED-TEAM VERDICT: CLEAN

OUT-OF-MODEL:
  - The post-step-3 `lookupUser` re-fetch in `InboundRouter.java` assumes the
    just-inserted row will be returned by the immediately-following SELECT. If
    `autoRegisterService.resolveOrRegisterGroup` silently fails to insert (no
    exception propagated) or if a concurrent process deletes the row between
    insert and re-fetch, `snapshot` remains empty and the subsequent
    `snapshot.get().registrationState()` / `snapshot.get().id()` NPEs. The
    crash short-circuits dispatch with no reply rather than bypassing
    authorization, so no security boundary is crossed — but the defensive
    `snapshot.isPresent()` guard the redteam round-2 acceptance text removed
    is now the load-bearing invariant. Outside the threat model's commitments
    — flagging as advisory. Re-adding the guard would re-violate the
    engineering rule §No defensive code; AutoRegisterService's contract (insert
    or throw) is the right enforcement layer.
  - `VouchCommandHandler` writes no audit row for the banned-target rejection
    path: an admin invoking `/vouch <banned-contact>` leaves no audit trace of
    the attempt. The spec's §Authorization model step 8 says "Audit-log the
    intent" between permission check and execute, which would suggest
    intent-logging this rejection. The handler's chosen pattern follows the
    M1-036 `/unban` no-op precedent (no audit row for in-effect no-ops), which
    appears to be an internal convention rather than a threat-model
    commitment. The spec's `/vouch` audit promise ("The vouch is
    audit-logged") references the success path. Flagged as advisory.
  - The actor `lookupActorForUpdate` in `VouchCommandHandler.java` reads
    `is_admin` but not `is_banned`. A banned bot admin who bypassed step 4
    (impossible in the current router, but the handler does not defend
    against it) could pass the admin check. The threat model relies on step
    4 being the sole defense, so internal-trust-boundary rules apply (no
    defensive code between internal classes per the engineering rule).
    Flagged for awareness.
