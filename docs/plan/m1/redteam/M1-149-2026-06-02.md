RED-TEAM VERDICT: CLEAN

The diff (M1-149) percent-encodes the upstream-supplied pagination cursor
(`cursor` in `BlueskyFetcher.buildUri`, `afterCursor` in
`RedditFetcher.buildPageUri`) before concatenating it into the next-page
query string. This directly serves the threat-model assumption "The
Collector is exposed to arbitrary feed content... Every RSS publisher,
Reddit poster, Bluesky user, etc. is untrusted" — it closes a
query-parameter-injection / URL-truncation gap at the correct trust
boundary rather than opening one.

Checks performed against the threat model:
- INJECTION: `URLEncoder.encode(..., UTF_8)` escapes `&`, `#`, `?`, `=` to
  `%26/%23/%3F/%3D`, so a malicious cursor can no longer add a second
  `actor=`/`after=` parameter or truncate the URL with a fragment. The
  accompanying tests assert exactly this (single `actor`/`after` param,
  percent-encoded token). No residual metacharacter escape.
- SSRF (§SSRF and outbound connections): the constructed `URI` is still
  passed through `SsrfGuardedHttpClient.get(...)` (`BlueskyFetcher.java:82`,
  `RedditFetcher.java:74`), so the DNS/IP-blocklist, redirect, and timeout
  guarantees are untouched. The encoded cursor lands only in the query
  component; host, scheme, and path remain the fixed, operator-configured
  base, so the cursor cannot redirect the outbound target. Encoding does not
  weaken the per-hop re-resolution guarantee (that lives inside the guarded
  client, unaffected).
- INFO-LEAK / §User content in exceptions: fetcher exception messages
  interpolate `UrlRedactor.redact(identifier)` only and never the raw
  cursor; the diff adds no new log/exception sink for upstream content.
- The unencoded `actor`/`identifier` interpolation that remains
  (`BlueskyFetcher.java:114`, `RedditFetcher.java:111`) is the source
  identifier, which is operator-set config (trusted per threat model
  "Operator-set config... is trusted"), not untrusted feed content — out of
  the cursor's untrusted-injection scope and unchanged by this diff.
- Sensitive-surface inventory confirms no auth, ban, audit-log, admin-tier,
  or LLM-tool surface is touched; the only entries are input-validation
  fetcher paths.

No threat-model commitment is left undelivered by this diff, and no new gap
is introduced.
