RED-TEAM VERDICT: FINDINGS

FINDINGS:
  - CATEGORY: DOS
    SEVERITY: high
    PROMISE: "Everything a generative or embeddings endpoint returns is endpoint-chosen input" and "the response body is read under an operator-configurable cap (clamped to 1–8 MiB) before parsing, so a pathological multi-GB reply cannot exhaust the JVM."
    GAP: QueryTranslationCache.java:42-45 retains up to 10,000 entries for 24 hours by entry count only, while QueryAnchorTranslator.java:173-176 accepts the translator response verbatim and QueryAnchorTranslator.java:184 stores it without a byte/weight bound. A hostile endpoint can return an in-cap multi-megabyte translation for every distinct query, converting the transport cap into tens of gigabytes of retained heap.
    REPRO: A registered user sets a non-English scope language and sends distinct chat queries until the cache fills. For each cache miss, a hostile or compromised configured translator endpoint returns an 8 MiB nonblank response. Each response is accepted and retained for 24 hours; enough misses exhaust the Provider heap and make it unavailable.
    SUGGESTED-FIX-CLASS: input-sanitization
  - CATEGORY: INFO-LEAK
    SEVERITY: medium
    PROMISE: "The presentation-layer translation cache ... is shared across scopes" is accepted only because "the cached strings are presentation prose generated by the bot ... not user-authored content."
    GAP: QueryTranslationCache.java:39 and :75-77 key the application-scoped cache solely by raw sourceText and sourceLanguage, omitting user and scope. QueryAnchorTranslator.java:151-154 returns a hit before the translator call. Unlike the documented presentation cache, these keys are user-authored search queries, so the hit/miss latency is a cross-scope oracle for another user's query.
    REPRO: An attacker with a non-English scope times a chat turn containing a guessed sensitive query and language. If another scope issued the same query during the 24-hour TTL, the deterministic pre-fetch skips the translator HTTP call; otherwise it performs it. Repeating calibrated guesses reveals whether another user searched for each candidate phrase.
    SUGGESTED-FIX-CLASS: trust-boundary-tightening
