    campaign bounds the cost (one rebuild attempt per ladder rung, 60 s
    steady state, loopback TCP probe + handshake each, virtual threads
    only), and security.md explicitly scopes out supply-chain/operator-
    infrastructure compromise, so this is noted for the record rather than
    counted: the residual is a rolling availability degradation with correct
    gauge/connected() visibility, not an unbounded resource sink.

    v1 non-commitment in the amended spec text (so no promise-vs-delivery
    gap), and security.md documents no transport-liveness-honesty
    commitment for adapters — recorded here in case the user wants the
    threat model to take a position on Signal liveness.
