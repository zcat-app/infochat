    cardinality (the new llm.md bullet this diff adds) and to
    content-level distrust of LLM output, but nowhere to the integrity
    of provider-reported numeric usage values ("Prometheus counter
    names and recommended alert expressions" live in design notes), so
    this is flagged for a possible model extension (clamp/validate
    usage values or treat them as untrusted input), not counted as a
    finding.
